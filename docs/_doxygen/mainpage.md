# AS5047U Driver API reference {#mainpage}

The classes, members and registers of the HardFOC AS5047U driver, generated from the headers.

Start with as5047u::AS5047U, the driver, and as5047u::SpiInterface, the interface your platform port implements.
The typed registers are in the AS5047U_REG namespace; FrameFormat, FilterPreset and AS5047U_Error are global
enums, and the compile-time defaults are in AS5047U_CFG.

The guides, with examples that compile, are on the documentation site: <a href="../">AS5047U Driver
documentation</a>.
