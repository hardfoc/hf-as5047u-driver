Detailed Description

template<typename T>
struct as5047u::Result< T >

Value of a getter together with the error of the read that produced it.

Every value getter returns one. On success error is AS5047U_Error::None and value holds the reading. On failure error says why (BusError, ReplyCrcError, or the CrcError / FramingError the chip reported in ERRFL for the access) and value is value-initialised (0): it is not a reading and must not be used. The cause is also in the sticky flags (AS5047U::GetStickyErrorFlags()).
