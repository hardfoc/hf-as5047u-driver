Detailed Description

template<typename SpiType>
class as5047u::AS5047U< SpiType >

AS5047U magnetic rotary sensor driver class.

Provides high-level access to sensor features: reading angle (with or without DAEC compensation), reading rotation velocity, retrieving AGC and magnitude diagnostics, configuring outputs (ABI, UVW, PWM), handling error flags, and performing OTP programming for permanent configuration storage.

Template Parameters
SpiTypeThe SPI bus type (must inherit from as5047u::SpiInterface<SpiType>)
Note
The driver uses CRTP-based SPI interface for zero virtual call overhead. SPI implementations should inherit from as5047u::SpiInterface<DerivedType>
C++17 CTAD allows automatic type deduction: AS5047U encoder(bus, format); // Type deduced automatically

Configure interface outputs (ABI, UVW) and PWM output.

Enables/disables ABI and UVW outputs and configures PWM on the available pin:

  • If abi is true and uvw false, ABI outputs are enabled and PWM (if enabled) is on W pin.
  • If uvw is true and abi false, UVW outputs are enabled and PWM (if enabled) is on I pin.
  • If both abi and uvw are true, both interfaces are active (PWM not available in this mode).
  • If both are false, all interfaces are disabled (PWM can still be enabled on W by default).
Parameters
abiEnable ABI (A, B, I) outputs.
uvwEnable UVW commutation outputs.
pwmEnable PWM output on the appropriate pin (W if UVW disabled, I if ABI disabled).

Read the ERRFL register (0x0001) from the chip.

The chip clears ERRFL when it is read (datasheet Figure 33), so the value covers only what happened since the driver's previous read of ERRFL. Every ERRFL value the driver reads, including this one, is also ORed into the sticky flags (GetStickyErrorFlags()), so nothing read here is lost.

Parameters

Returns
Result: in value, the OR of every ERRFL value read; error set only when no attempt succeeded (the bus or the reply failed every time).

◆ ProgramOTP()

template<typename SpiType >
bool as5047u::AS5047U< SpiType >::ProgramOTP ( OtpResult *  result = nullptr)

Permanently program the current settings into OTP memory.

Runs steps 4 to 19 of the datasheet's "Step-by-Step Procedure to Permanently Program the Non-Volatile Memory (OTP)" (DS000637 v1-01, page 41-42, flowchart Figure 60), checking the result of every step and stopping at the first that fails:

  1. read ANGLECOM; 5. write it into ZPOSL[5:0] and ZPOSM[7:0];
  2. read DISABLE..ECC (0x0015..0x001B); 7. ECC = 0x80 (ECC_en);
  3. read ECC_s (0x3FD0); 9. ECC = 0x80 | ECC_s;

read 0x0015..0x001B; 11. compare with what was written;

  1. PROG = 0x01 (PROGEN); 13. PROG = 0x08 (PROGOTP, starts the burn);
  2. poll PROG until it reads 0x0001;
  3. write 0x0000 into 0x0015..0x001B (clear the volatile copy);
  4. PROG = 0x40 (PROGVER, guard band); 17. PROG = 0x04 (OTPREF, reload from OTP); 18. read 0x0015..0x001B; 19. compare with step 10.

Steps 1 to 3 (power-on cycle, write the settings, magnet at the zero position) come before the call; steps 20 to 22 (power-on cycle, read back, compare) after it, with VerifyOTP() and the image in result. 16-bit frames are replaced by 24-bit frames for the duration.

Parameters
resultOptional: the step that failed, whether the burn was started, and the register image that was burned.
Returns
true if every step succeeded and the guard-band comparison (step 19) matched.
Warning
OTP can be programmed only once, and a part that fails step 19 must not be used (datasheet: "Reprogramming is not allowed!"). VDD 4.5 to 5.5 V (5 V mode) or 3.3 to 3.5 V (3.3 V mode), 5 to 45 degC (Figure 59).
